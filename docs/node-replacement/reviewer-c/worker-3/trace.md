## ADR-007..009 Evidence Run

Synthetic trigger, persistent-task, and network-mutation fixtures plus one focused evidence test were added under C3-authorized test paths only. The task fixture proves current persisted task fields are raw definition/owner identity without revision/catalog/plan fields.
