# ReSync Node Replacement Evidence Pack

This directory is the durable evidence and decision surface for the node-system replacement defined in `plan.md`. The plan, `AGENTS.md`, and `RESYNC_RULES.md` remain governing inputs and are not copied here.

Gate state: **Gate 0A approved; Gate 0B in progress and unfrozen**.

Gate 0A was accepted on 2026-08-02 after all three reviewers signed the current-system traces and the focused ReSync and Remotely evidence suites passed. Gate 0B artifacts remain living documents until all target contracts, golden fixtures, budgets, and reviewer approvals are frozen.

- `governance.md`: repository state, ownership, writable paths, dependency and merge order.
- `architecture-dossier.md`: current startup, catalog, persistence, protocol, client, execution, extension, migration, snapshot, and restore paths.
- `problem-ledger.md`: evidence-backed replacement problems and retirement proofs.
- `behavior-matrix.md`: observable behavior and invariants by system/domain.
- `current-to-target.md`: retain/adapt/replace/delete classification.
- `compatibility-matrix.md`: supported product, contract, platform, and persisted-format combinations.
- `fixture-manifest.md`: current and required sanitized fixtures.
- `baseline-metrics.md`: raw catalog counts and reproducible performance measurements.
- `decision-log.md`: cross-domain decisions and rejected alternatives.
- `contract-freeze-ledger.md`: shared contracts and their freeze state.
- `reviewer-a/`, `reviewer-b/`, `reviewer-c/`: reviewer-owned evidence and approvals.
