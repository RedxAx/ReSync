# Reoverwhelming You!
ReSync have gone through many changes and feature! It's probably the biggest update sense 1.0. Here's the breakdown:
- ReSync networks! Sync items, data, permissions, and more to some items, and join rules (e.g. Join to the lowest player count server), and way more!
- Trading! You can now create trading profiles, which includes any items (Vanilla, ReSync, Providers (e.g. Nexo)), and open it anywhere, even with just a command!
- NPCs! You can now create any entity as an NPC, add items to them, add bind any functions to them!
- Item Attributes And Components! You can use any vanilla component, this is a very powerful system, more than you'll ever think! You can also quick edit any item with `/resync quickedit`, which will allow you to edit an item without adding it to your ReSync library.
- Loot Tables! You can override any vanilla loot table (For example, block breaks, entity drops, etc.), With any items you want.
- Semi-Finished LuckPerms Dashboard In The ReSync Studio, note that it's not finished and will get a UI overhaul.
- Many changes to nodes, which allow them to be much more powerful and usable. Trust me on this one!
- ReSync Now Support 1.21 - 26.2! Along with Velocity!
